How to add events from Google Sheets to Google Calendar (2026)

You have a schedule in Google Sheets™ — classes, shifts, lessons, a content plan — and you want it in Google Calendar™ so people get reminders on their phones. Here are three ways, from free-and-manual to automatic.

Option 1: Import a CSV (one-off, no updates)

  1. Rename your columns to Subject, Start Date, Start Time, End Date, End Time, Location, Description.
  2. File → Download → Comma-separated values (.csv).
  3. In Google Calendar: Settings → Import & export → Import, choose the file and the calendar.

Catch: it's a one-time copy. Change a time in the sheet and the calendar won't know; import again and you get duplicates.

Option 2: A small Apps Script (free, for the technical)

Extensions → Apps Script, paste and run:

function addEvents() {
  const cal = CalendarApp.getDefaultCalendar();
  const rows = SpreadsheetApp.getActiveSheet().getDataRange().getValues().slice(1);
  rows.forEach(([title, start, end]) => {
    if (title && start && end) cal.createEvent(title, new Date(start), new Date(end));
  });
}

Catch: every run creates the events again. To update or delete you need to store event IDs, handle time zones, text dates, all-day events and API limits — that's where most scripts break.

Option 3: EventRows (free to start, keeps everything in sync)

  1. Install EventRows from the Google Workspace Marketplace.
  2. Extensions → EventRows → Open, pick a calendar.
  3. Check the detected columns (Title, Date, Time, End, Location, Guests) and press Sync.

Edit a row and sync again — the same event updates. Delete a row — the event is removed. Rows with a problem are listed with their row number instead of silently failing. The free plan covers 30 new events a month.

Tips for a clean schedule sheet

  • One event per row; keep the header row at the top.
  • Use real date cells (Format → Number → Date) or ISO text like 2026-09-25.
  • Overnight shifts: put 22:00 as start and 06:00 as end — EventRows moves the end to the next day.
  • Guests: put emails in one cell separated by commas; they receive invitations.
